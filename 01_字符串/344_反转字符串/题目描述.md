# 344. 反转字符串

## 题目描述

编写一个函数，其作用是将输入的字符串反转过来。输入字符串以字符数组 `s` 的形式给出。

不要给另外的数组分配额外的空间，你必须**原地修改输入数组**、使用 O(1) 的额外空间解决这一问题。

## 示例

**示例 1：**
```
输入：s = ["h","e","l","l","o"]
输出：["o","l","l","e","h"]
```

**示例 2：**
```
输入：s = ["H","a","n","n","a","h"]
输出：["h","a","n","n","a","H"]
```

## 约束

- `1 <= s.length <= 10^5`
- `s[i]` 都是 ASCII 码表中的可打印字符

## 解题思路

**双指针法**：
- 左指针 `left` 从数组头部开始，右指针 `right` 从数组尾部开始
- 交换 `s[left]` 和 `s[right]`
- `left` 右移，`right` 左移，直到 `left >= right`

**时间复杂度**：O(n)，n为字符串长度
**空间复杂度**：O(1)，原地修改
