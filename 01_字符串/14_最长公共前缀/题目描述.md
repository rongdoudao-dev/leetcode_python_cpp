# 14. 最长公共前缀

## 题目描述

编写一个函数来查找字符串数组中的最长公共前缀。

如果不存在公共前缀，返回空字符串 `""`。

## 示例

**示例 1：**
```
输入：strs = ["flower","flow","flight"]
输出："fl"
```

**示例 2：**
```
输入：strs = ["dog","racecar","car"]
输出：""
解释：输入不存在公共前缀。
```

## 约束

- `1 <= strs.length <= 200`
- `0 <= strs[i].length <= 200`
- `strs[i]` 仅由小写英文字母组成

## 解题思路

**纵向扫描法**：
- 以第一个字符串为基准，逐列比较所有字符串的第 `i` 个字符
- 如果某字符串长度不足 `i`，或第 `i` 个字符不同，则返回 `strs[0][:i]`
- 全部匹配则继续下一列

**时间复杂度**：O(mn)，m=字符串平均长度，n=字符串数量
**空间复杂度**：O(1)
