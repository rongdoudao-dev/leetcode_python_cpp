## 核心语法对比速记

### Python vs C++ 最常考的10个区别

1. **缩进 vs 大括号**：Python靠缩进，C++靠`{ }`
2. **动态类型 vs 静态类型**：Python `x=10`，C++ `int x=10;`
3. **分号**：Python不需要，C++必须`;`
4. **列表 vs vector**：Python `list`，C++ `std::vector<T>`
5. **字典 vs unordered_map**：Python `dict`，C++ `std::unordered_map<K,V>`
6. **for循环**：Python `for x in list:`，C++ `for (auto& x : list) {}`
7. **函数定义**：Python `def f(x):`，C++ `int f(int x) {}`
8. **类定义**：Python `class A:`，C++ `class A {};`
9. **None vs nullptr**：Python空值`None`，C++空指针`nullptr`
10. **异常**：Python `try/except`，C++ `try/catch`

## 面试建议

1. **每道题先想思路再写代码**：口述算法→时间复杂度→边界条件
2. **Python写得快，C++考基础**：面试一般两种语言选一种，建议Python为主
3. **高频题必须背熟**：链表反转、二分查找、滑动窗口、DP、LRU是必考题
4. **注意边界条件**：空输入、单元素、溢出、索引越界
5. **复杂度分析必说**：时间复杂度+空间复杂度，能优化就说优化方案
