# 49. 字母异位词分组

## 题目描述

给你一个字符串数组，请你将 **字母异位词** 组合在一起。可以按任意顺序返回结果列表。

**字母异位词** 是由重新排列源单词的所有字母得到的一个新单词。

## 示例

**示例 1：**
```
输入: strs = ["eat", "tea", "tan", "ate", "nat", "bat"]
输出: [["bat"],["nat","tan"],["ate","eat","tea"]]
```

**示例 2：**
```
输入: strs = [""]
输出: [[""]]
```

**示例 3：**
```
输入: strs = ["a"]
输出: [["a"]]
```

## 约束

- `1 <= strs.length <= 10^4`
- `0 <= strs[i].length <= 100`
- `strs[i]` 仅包含小写字母

## 解题思路

**排序键 + 哈希表**：
- 字母异位词排序后结果相同（如 "eat"、"tea"、"ate" 排序后都是 "aet"）
- 用排序后的字符串作为 key，原字符串加入对应 value 列表
- 最后返回哈希表的所有 value

**时间复杂度**：O(n * k * log k)，n=字符串数，k=字符串最大长度
**空间复杂度**：O(n * k)
