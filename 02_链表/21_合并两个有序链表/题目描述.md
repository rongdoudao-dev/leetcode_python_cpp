# 21. 合并两个有序链表

## 题目描述

将两个升序链表合并为一个新的 **升序** 链表并返回。新链表是通过拼接给定的两个链表的所有节点组成的。

## 示例

**示例 1：**
```
输入：l1 = [1,2,4], l2 = [1,3,4]
输出：[1,1,2,3,4,4]
```

**示例 2：**
```
输入：l1 = [], l2 = []
输出：[]
```

**示例 3：**
```
输入：l1 = [], l2 = [0]
输出：[0]
```

## 约束

- 两个链表的节点数目范围是 `[0, 50]`
- `-100 <= Node.val <= 100`
- `l1` 和 `l2` 均按 **非递减顺序** 排列

## 解题思路

**虚拟头节点 + 双指针**：
- 创建虚拟头节点 `dummy`，`current` 指向 dummy
- 比较 `list1.val` 和 `list2.val`，将较小的节点接在 current 后面
- 对应链表指针后移，current 后移
- 某一链表遍历完后，将另一链表剩余部分直接接上

**时间复杂度**：O(n+m)
**空间复杂度**：O(1)
